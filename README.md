# Weather API Script By Bashir Muhammed

## Setup Steps

After cloning into the repository, open your terminal and cd into the folder directory.

Type in `python3 -m venv venv`

This is to create a virtual environment to run the python code so as to allow to create isolated environments for different projects, allowing each project to manage its own specific set of Python packages and versions without interfering with other projects or the system's global Python installation. 

Then type `source venv/bin/activate` for MacOS or Linux then `venv\Scripts\activate` for windows to go into the virtual env.

your directory would look similar to `(venv) yvgeny@yvgeny-VivoBook-ASUSLaptop-X509FAC-X509FA` once the virtual environment is open

`deactivate` is used to close the virtual environment

To run the code type `python3 main.py`

NOTE: External dependencies such as dotenv are used in this project
